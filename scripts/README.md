# NeuroMiner Data Processing Scripts

This directory contains post-processing and benchmarking tools for NeuroMiner OBS
session data.

The scripts are intended for world-model training pipelines that need precise alignment
between recorded video frames and OS-level input events.

## Requirements

- Python `>= 3.13`
- Dependencies listed in `pyproject.toml` (`numpy`, `opencv-python`)

This project uses `uv` for environment and dependency management.

```bash
cd scripts
uv sync
```

Run scripts with `uv run`:

```bash
cd scripts
uv run python estimate_latency.py /path/to/<UUID>/
```

## Input Session Layout

Most scripts operate on a single session directory (`<UUID>/`) generated by the plugin:

- `recording.mp4` (or another extension depending on OBS output format)
- `actions.jsonl`
- `events.jsonl`
- `metadata.json`

## Scripts

### `benchmark_app.py`

Interactive visual benchmark app (black/white toggle on `SPACE`) for controlled
latency ground-truth experiments.

### `benchmark_analyze.py`

Ground-truth latency analyzer for benchmark sessions.
It matches `SPACE` key events to brightness transitions in recorded video.

```bash
cd scripts
uv run python benchmark_analyze.py /path/to/<UUID>/
uv run python benchmark_analyze.py /path/to/<UUID>/ --max-latency-ms 800
uv run python benchmark_analyze.py /path/to/<UUID>/ --space-from-actions
```

### `estimate_latency.py`

Automatic latency estimator for normal gameplay sessions.
Writes estimated `input_latency_bias_ms` back into `metadata.json`.

```bash
cd scripts
uv run python estimate_latency.py /path/to/<UUID>/
uv run python estimate_latency.py /path/to/<UUID>/ --dry-run
uv run python estimate_latency.py /path/to/<UUID>/ --window-size 45 --threshold-sigma 2.5 --max-latency-ms 300
```

### `evaluate_alignment.py`

Residual quality report after median-bias calibration.
Use this to quantify whether a session is good enough for action-conditioned training.

```bash
cd scripts
uv run python evaluate_alignment.py /path/to/<UUID>/
uv run python evaluate_alignment.py /path/to/<UUID>/ --window-size 45 --threshold-sigma 4.0 --max-latency-ms 120
uv run python evaluate_alignment.py /path/to/<UUID>/ --json-output ./reports/<UUID>.json
```

### `apply_offset.py`

Simple frame-shift alignment utility.
Useful for quick checks; less precise than event resampling.

```bash
cd scripts
uv run python apply_offset.py /path/to/<UUID>/
uv run python apply_offset.py /path/to/<UUID>/ --bias-ms 50 --output actions_aligned_quick.jsonl
```

### `resample_events.py`

High-precision event-to-frame resampling.
Reconstructs aligned per-frame states from raw sub-frame events (`events.jsonl`).

```bash
cd scripts
uv run python resample_events.py /path/to/<UUID>/
uv run python resample_events.py /path/to/<UUID>/ --bias-ms 50 --output actions_resampled_custom.jsonl
```

## Suggested Workflow

1. Collect a session with the OBS plugin.
2. Estimate session latency and write `input_latency_bias_ms`:

```bash
cd scripts
uv run python estimate_latency.py /path/to/<UUID>/
```

3. Evaluate residual alignment quality:

```bash
cd scripts
uv run python evaluate_alignment.py /path/to/<UUID>/
```

4. Generate high-precision aligned frame actions:

```bash
cd scripts
uv run python resample_events.py /path/to/<UUID>/
```

5. Use `actions_resampled.jsonl` for downstream training ingestion.
